# Участие в проекте

Спасибо за интерес к AlyaNovel! Мы ценим ваше желание помочь развивать проект

## Сообщить об ошибке или предложить идею

- Перед созданием Issue проверьте, не сообщал ли кто-то уже об этой проблеме.
- Опишите, что произошло, что вы ожидали увидеть и как повторить проблему.
- Для ошибки укажите версию приложения, модель устройства и версию Android.
- Не публикуйте пароли, токены, личные данные и другие секреты.

## Предложить изменения в коде

1. Создайте fork репозитория и отдельную ветку для изменений.
2. Перед большой или меняющей поведение правкой сначала создайте Issue и обсудите решение.
3. Делайте изменения небольшими и связанными с одной задачей.
4. Добавьте или обновите тесты, если это уместно.
5. Проверьте изменения локально и укажите в Pull Request, какие проверки запускали.
6. В описании Pull Request объясните, что изменено и зачем; приложите скриншоты для изменений интерфейса.

## Проверки

Для Android-приложения из каталога `alyanovel-app`:

```bash
./gradlew test
```

Для серверной части следуйте актуальным инструкциям по запуску и проверке из README.

## Стиль и совместимость

- Старайтесь следовать стилю существующего кода.
- Не добавляйте в коммиты секреты, ключи подписи, токены, локальные конфиги и пользовательские данные.
- Не включайте в изменения материалы, на которые у вас нет прав.
