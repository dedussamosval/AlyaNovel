# Политика конфиденциальности

**Версия:** 1.0 от 4 ноября 2026 г.

## 1. Общие положения

1.1. Политика описывает, какие данные обрабатываются при использовании приложения AlyaNovel и сайта проекта, для каких целей и как долго.

1.2. Читать каталог и главы можно без входа. Для чата требуется авторизация через Telegram. Обработка данных, необходимая для работы выбранных функций, происходит при их использовании.

## 2. Какие данные обрабатываются

2.1. **Запросы к серверу.** При обращении к серверу он получает технические сведения, необходимые для обработки запроса: IP-адрес, время, адрес запрошенного ресурса, результат запроса и переданные заголовки. IP-адрес используется, в частности, для ограничения частоты запросов; соответствующие счётчики хранятся в памяти сервера и сбрасываются при его перезапуске. Настройки сервера или хостинга также могут предусматривать журналы запросов и ошибок. Их состав и срок хранения зависят от этих настроек.

По запросам к каталогу и файлам сервер может определить, какие главы запрашивались. Приложение не передаёт серверу отметки о прочтении или историю чтения пользователя.

2.2. **Авторизация и чат Telegram.** При входе через Telegram сервер получает Telegram ID пользователя, username (если он указан) и имя, переданные Telegram-ботом. Сервер хранит эти сведения, хэш токена сессии и время её создания или продления. Сессия нужна для доступа к чату; её срок действия по умолчанию составляет 90 дней и может изменяться настройками сервера.

Сообщения, отправленные в чат, сохраняются на сервере вместе с текстом, именем, Telegram ID отправителя и временем отправки и показываются другим пользователям чата. В коде не задан автоматический срок удаления сообщений.

Для начала входа создаётся временный токен авторизации. Незавершённые запросы очищаются при следующем запуске авторизации; срок действия такого запроса — 10 минут.

2.3. **Данные на устройстве.** Приложение хранит локально настройки интерфейса и уведомлений, список прочитанных глав, сведения о последнем просмотре новинок, загруженные главы и кэш. При входе локально также сохраняются токен сессии и имя пользователя. Эти данные не передаются серверу, за исключением токена и имени, необходимых для работы чата.

2.4. **Push-уведомления.** Если пользователь включил уведомления о новых главах, устройство подписывается на тему Firebase Cloud Messaging (FCM). Сервер отправляет в эту тему сведения о новой главе для доставки подписанным устройствам. Сервер проекта не хранит список FCM-токенов устройств. Обработка данных, необходимых для доставки уведомлений, осуществляется Firebase в соответствии с [политикой конфиденциальности Google](https://firebase.google.com/support/privacy).

2.5. Приложение не содержит рекламы и не использует рекламные идентификаторы. В коде приложения отсутствует встроенная система аналитики или автоматической отправки отчётов о сбоях.

## 3. Цели обработки

Данные обрабатываются только для работы каталога, загрузки глав, авторизации и чата, защиты сервера от злоупотреблений, а также доставки включённых пользователем push-уведомлений.

## 4. Хранение и удаление

4.1. Локальные настройки, токен и загруженные главы хранятся на устройстве до удаления пользователем, очистки данных приложения или удаления приложения.

4.2. Серверные сессии чата удаляются после истечения срока действия при очередной очистке базы; срок по умолчанию — 90 дней с момента последнего продления. Записи пользователя в базе не удаляются автоматически вместе с сессией. Незавершённые запросы авторизации очищаются при следующем запуске авторизации.

4.3. Сообщения чата хранятся до удаления администратором или удаления базы данных; автоматический срок хранения в коде не установлен. Журналы сервера и хостинга хранятся в соответствии с настройками соответствующих систем.

4.4. Токены сессий в базе хранятся в виде хэша. Команда принимает разумные меры для ограничения доступа к данным, но не может гарантировать абсолютную безопасность передачи или хранения информации.

## 5. Передача третьим лицам

5.1. Данные не продаются и не передаются третьим лицам в коммерческих целях.

5.2. Telegram обрабатывает данные, необходимые для входа через бота и работы Telegram, по своей [политике конфиденциальности](https://telegram.org/privacy). Firebase обрабатывает данные, необходимые для доставки push-уведомлений.

5.3. Данные могут быть предоставлены уполномоченным органам при наличии законного требования. Провайдер хостинга может обрабатывать технические данные запросов в рамках оказания услуг.

## 6. Права пользователя и обращения

Пользователь вправе запросить сведения об обрабатываемых данных, потребовать их удаления в случаях и порядке, предусмотренных законом, а также прекратить использование чата, удалив токен из приложения. Выход из приложения удаляет локальные данные сессии, но сам по себе не удаляет серверную запись пользователя и уже отправленные сообщения. Для запроса на удаление серверных данных следует обратиться по контактам ниже.
