О проекте

Это некоммерческий проект Команды Telegram-канала alya_novel: приложение для чтения любительского перевода новеллы и манги "Аля иногда кокетничает со мной по-русски". Без рекламы; проект может поддерживаться добровольными пожертвованиями.

📚 Ранобэ и манга

Два раздела со списком томов и глав — новые главы появляются сразу после загрузки.

📴 Офлайн-чтение

Скачивайте главы заранее и читайте без интернета; можно ограничить загрузку только Wi-Fi.

💬 Чат читателей

Обсуждайте главы с другими читателями. Вход через Telegram, без паролей.
